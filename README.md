# SessaoZero
Repositório para o Trabalho de Conclusão de Curso de Ruan Barbosa Araújo e Samuel França Barreto Filho, estudantes do Curso de Ciência da Computação.

## Descrição do projeto
A Sessão Zero é uma rede social voltada para jogadores de RPG de mesa, criada para aproximar mestres e jogadores na organização de sessões, one-shots e campanhas. Mestres podem publicar a sinopse de uma mesa, informando o sistema utilizado e demais detalhes relevantes, permitindo que jogadores interessados encontrem e se conectem com facilidade. Há um sistema de avaliação individual sobre cada pessoa, de jogador para mestre e mestre para jogadores, facilitando a integração entre indivíduos.

## Tecnologias Utilizadas
 
- **Python** — linguagem principal do backend
- **Django** — framework web utilizado para estruturar a aplicação
- **HTML** — estruturação das páginas
- **CSS** — estilização das páginas
- **JavaScript** — interatividade no lado do cliente
- **MongoDB** — banco de dados utilizado para o registro e a organização das informações
## Pré-requisitos
 
A Sessão Zero é um site público, então não é necessário instalar nenhum software para utilizá-la. Basta ter:
 
- Um dispositivo (computador, notebook, tablet ou smartphone) com hardware suficiente para rodar um navegador web moderno
- Um navegador atualizado, como Google Chrome, Mozilla Firefox, Microsoft Edge, ou similar
- Conexão com a internet
